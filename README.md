# rftinternship_day14

This project creates a Pie Chart using Python and Matplotlib to visualize expense distribution across different categories.

The main objective of this project is:
- To learn Pie Chart visualization
- To understand percentage representation
- To highlight important data categories
- To visualize proportional data


Labels
- Displays category names on chart slices.

Autopct
- Displays percentage values on chart.
- %1.1f%% means one digit after decimal.

Explode
- Separates selected slice from pie chart.
- Used to highlight important category.

Shadow
- Adds shadow effect to the chart.

Startangle
- Rotates chart starting position by 90
